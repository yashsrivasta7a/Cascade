## 1. Get Your API Key

First, log into your Flowsmith dashboard and navigate to **Settings → API Keys** to generate a new API key.

<Warning>
  Keep your API key secure! Never expose it in client-side code or public repositories.
</Warning>

## 2. Make Your First Request

Test your API key by fetching your credit balance:

<CodeGroup>

```bash cURL
curl -X GET "https://flowsmiths.vercel.app/api/v1/credits/balance" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript JavaScript
const response = await fetch('https://flowsmiths.vercel.app/api/v1/credits/balance', {
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY'
  }
});

const data = await response.json();
console.log(data);
```

```python Python
import requests

response = requests.get(
    'https://flowsmiths.vercel.app/api/v1/credits/balance',
    headers={'Authorization': 'Bearer YOUR_API_KEY'}
)

print(response.json())
```

</CodeGroup>

## 3. List Your Workflows

Fetch all your workflows:

```bash
curl -X GET "https://flowsmiths.vercel.app/api/v1/workflows" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

## 4. Execute a Workflow

Trigger a workflow execution:

```bash
curl -X POST "https://flowsmiths.vercel.app/api/v1/workflows/{workflow_id}/execute" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"inputs": {}}'
```
