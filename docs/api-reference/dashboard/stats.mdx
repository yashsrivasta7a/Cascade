## Overview

Returns aggregate statistics for the authenticated user's dashboard, including workflow counts, execution metrics, and credit usage.

## Request

<CodeGroup>
```bash cURL
curl -X GET https://flowsmiths.vercel.app/api/v1/dashboard/stats \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript JavaScript
const response = await fetch(
  'https://flowsmiths.vercel.app/api/v1/dashboard/stats',
  {
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    }
  }
);
const data = await response.json();
```

```python Python
import requests

response = requests.get(
    'https://flowsmiths.vercel.app/api/v1/dashboard/stats',
    headers={'Authorization': 'Bearer YOUR_API_KEY'}
)
data = response.json()
```
</CodeGroup>

## Response

<ResponseField name="workflows" type="object">
  Workflow statistics
  <Expandable title="Workflows Object">
    <ResponseField name="total" type="integer">
      Total number of workflows
    </ResponseField>
    <ResponseField name="thisWeek" type="integer">
      Workflows created this week
    </ResponseField>
    <ResponseField name="active" type="integer">
      Workflows with recent executions
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="executions" type="object">
  Execution statistics
  <Expandable title="Executions Object">
    <ResponseField name="total" type="integer">
      Total number of executions
    </ResponseField>
    <ResponseField name="thisWeek" type="integer">
      Executions this week
    </ResponseField>
    <ResponseField name="running" type="integer">
      Currently running executions
    </ResponseField>
    <ResponseField name="successRate" type="string">
      Success rate percentage
    </ResponseField>
    <ResponseField name="avgDuration" type="string">
      Average execution duration
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="credits" type="object">
  Credit statistics
  <Expandable title="Credits Object">
    <ResponseField name="balance" type="number">
      Current credit balance
    </ResponseField>
    <ResponseField name="usedThisWeek" type="number">
      Credits used this week
    </ResponseField>
    <ResponseField name="usedThisMonth" type="number">
      Credits used this month
    </ResponseField>
    <ResponseField name="usedTotal" type="number">
      Total credits used (all time)
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="recentActivity" type="array">
  Recent workflow activity
  <Expandable title="Activity Item">
    <ResponseField name="id" type="string">
      Execution ID
    </ResponseField>
    <ResponseField name="workflowName" type="string">
      Name of the workflow
    </ResponseField>
    <ResponseField name="status" type="string">
      Execution status
    </ResponseField>
    <ResponseField name="timestamp" type="string">
      ISO timestamp of the activity
    </ResponseField>
    <ResponseField name="cost" type="number">
      Credits consumed
    </ResponseField>
  </Expandable>
</ResponseField>

## Use Cases

- **Dashboard Overview** - Display key metrics at a glance
- **Usage Monitoring** - Track credit consumption over time
- **Performance Analysis** - Monitor execution success rates
- **Activity Feed** - Show recent workflow activity

<Tip>
This endpoint is optimized for dashboard loading. For more detailed statistics, use the individual endpoints for [executions](/api-reference/executions/list) or [credits](/api-reference/credits/stats).
</Tip>
