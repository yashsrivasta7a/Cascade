<Note>
This endpoint streams LLM responses character-by-character using **Server-Sent Events (SSE)**. For non-streaming LLM execution, use [Execute Node](/api-reference/nodes/execute) with `nodeType: "openrouter"`.
</Note>

## How It Works

1. Client sends a POST request with the prompt
2. Server establishes an SSE connection
3. As the LLM generates text, chunks are streamed to the client
4. When complete, a `done` event is sent with the full text

## Request

<ParamField body="prompt" type="string" required>
  The prompt to send to the LLM.
</ParamField>

<ParamField body="model" type="string" default="openai/gpt-4o-mini">
  Model ID from OpenRouter (e.g., `openai/gpt-4o`, `anthropic/claude-3-opus`).
</ParamField>

<ParamField body="systemPrompt" type="string">
  System prompt to set the LLM's behavior.
</ParamField>

<ParamField body="temperature" type="number" default="0.7">
  Sampling temperature (0-2). Higher = more creative.
</ParamField>

<ParamField body="maxTokens" type="number" default="4096">
  Maximum tokens in the response.
</ParamField>

<ParamField body="topP" type="number">
  Nucleus sampling parameter (0-1).
</ParamField>

<ParamField body="frequencyPenalty" type="number">
  Reduce repetition (-2 to 2).
</ParamField>

<ParamField body="presencePenalty" type="number">
  Encourage new topics (-2 to 2).
</ParamField>

<ParamField body="context" type="string">
  Additional context to include.
</ParamField>

<ParamField body="imageUrl" type="string">
  Image URL for vision models.
</ParamField>

<ParamField body="useCache" type="boolean" default="false">
  Return cached result if available.
</ParamField>

## Response Format

The response is a stream of Server-Sent Events:

### Chunk Event
Sent as each piece of text is generated:
```
data: {"type":"chunk","content":"Hello","partial":"Hello"}
```

### Done Event
Sent when generation is complete:
```
data: {"type":"done","text":"Hello, how can I help you today?"}
```

### Error Event
Sent if an error occurs:
```
data: {"type":"error","error":"API rate limit exceeded"}
```

## Example

### JavaScript/TypeScript

```typescript
async function streamLLM(prompt: string) {
  const response = await fetch('https://flowsmiths.vercel.app/api/nodes/llm/realtime', {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({
      prompt,
      model: 'openai/gpt-4o-mini',
      temperature: 0.7,
    }),
  });

  const reader = response.body?.getReader();
  const decoder = new TextDecoder();
  let fullText = '';

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    const chunk = decoder.decode(value);
    const lines = chunk.split('\n');

    for (const line of lines) {
      if (line.startsWith('data: ')) {
        const data = JSON.parse(line.slice(6));
        
        if (data.type === 'chunk') {
          console.log('Received:', data.content);
          fullText = data.partial;
        } else if (data.type === 'done') {
          console.log('Complete:', data.text);
          return data.text;
        } else if (data.type === 'error') {
          throw new Error(data.error);
        }
      }
    }
  }

  return fullText;
}
```

### cURL (for testing)

```bash
curl -X POST https://flowsmiths.vercel.app/api/nodes/llm/realtime \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Accept: text/event-stream" \
  -d '{
    "prompt": "Write a short poem about AI",
    "model": "openai/gpt-4o-mini"
  }' \
  --no-buffer
```

## Vision Models

For models with vision capabilities, include an image URL:

```json
{
  "prompt": "Describe what you see in this image",
  "model": "openai/gpt-4o",
  "imageUrl": "https://example.com/photo.jpg"
}
```

## Cached Responses

When `useCache: true` and a cached result exists, the response streams the full text immediately:

```
data: {"type":"chunk","content":"[full cached response]"}
data: {"type":"done","cached":true,"text":"[full cached response]"}
```

## Error Handling

| Status | Description |
|--------|-------------|
| `200` | Stream started successfully |
| `400` | Invalid request parameters |
| `401` | Missing or invalid authentication |
| `402` | Insufficient credits |
| `500` | Server error or OpenRouter API error |

## Credits

LLM requests consume credits based on:
- Model used (GPT-4 costs more than GPT-3.5)
- Input tokens (prompt length)
- Output tokens (response length)

Check your balance at [Credits Balance](/api-reference/credits/balance).
