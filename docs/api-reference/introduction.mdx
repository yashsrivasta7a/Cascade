## Base URL

```
https://cascade.vercel.app
```

<Note>
Most CRUD endpoints are under `/api/v1`, while execution and streaming endpoints are under `/api`. See the full paths in the endpoint table below.
</Note>

## OpenAPI Specification

The full OpenAPI 3.0 specification is available at:

```
https://cascade.vercel.app/api/openapi
```

You can import this into tools like Postman, Insomnia, or any OpenAPI-compatible client.

## Available Endpoints

### Workflows (under `/api/v1`)

Manage your AI workflows - create, update, and delete. These endpoints use the `/api/v1` base URL.

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/v1/workflows` | [List all workflows](/api-reference/workflows/list) |
| `GET` | `/api/v1/workflows/{id}` | [Get a specific workflow](/api-reference/workflows/get) |
| `POST` | `/api/v1/workflows` | [Create a new workflow](/api-reference/workflows/create) |
| `PATCH` | `/api/v1/workflows/{id}` | [Update a workflow](/api-reference/workflows/update) |
| `DELETE` | `/api/v1/workflows/{id}` | [Delete a workflow](/api-reference/workflows/delete) |
| `POST` | `/api/v1/workflows/{id}/duplicate` | [Duplicate a workflow](/api-reference/workflows/duplicate) |

### Workflow Execution (under `/api`)

Execute workflows. Note: This endpoint is NOT under `/api/v1`.

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/workflow/trigger` | [Execute a workflow](/api-reference/workflows/execute) |

### Executions (under `/api`)

Track and manage workflow executions. Note: These endpoints are NOT under `/api/v1`.

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/executions` | [List all executions](/api-reference/executions/list) |
| `GET` | `/api/executions/{id}` | [Get execution details](/api-reference/executions/get) |
| `GET` | `/api/executions/{id}/status` | [Get execution status (lightweight)](/api-reference/executions/status) |
| `POST` | `/api/executions/{id}/cancel` | [Cancel an execution](/api-reference/executions/cancel) |
| `GET` | `/api/executions/{id}/stream` | [Stream execution updates](/api-reference/executions/stream) |

### Credits (under `/api/v1`)

Monitor and manage your credit balance.

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/v1/credits/balance` | [Get current credit balance](/api-reference/credits/balance) |
| `GET` | `/api/v1/credits/stats` | [Get credit usage statistics](/api-reference/credits/stats) |

### Nodes (under `/api`)

Execute individual AI nodes programmatically. Note: These endpoints are NOT under `/api/v1`.

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/nodes/execute` | [Execute any node asynchronously](/api-reference/nodes/execute) |
| `GET` | `/api/nodes/status` | [Check node execution status](/api-reference/nodes/status) |
| `POST` | `/api/nodes/llm/realtime` | [Stream LLM responses (SSE)](/api-reference/nodes/llm-realtime) |

### Media (under `/api`)

Upload and manage media files.

| Method | Endpoint | Description |
|--------|----------|-------------|
| `POST` | `/api/media/upload` | [Upload media to CDN](/api-reference/media/upload) |

### Dashboard (under `/api`)

Get aggregate statistics and overview data.

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/api/dashboard/stats` | [Get dashboard statistics](/api-reference/dashboard/stats) |

## Response Format

All responses are returned as JSON with the following structure:

### Success Response

```json
{
  "data": { ... },
  "meta": {
    "requestId": "req_abc123"
  }
}
```

### Error Response

```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Workflow not found"
  }
}
```

## HTTP Status Codes

| Status | Description |
|--------|-------------|
| `200` | Success |
| `201` | Created successfully |
| `400` | Bad request - Invalid parameters |
| `401` | Unauthorized - Missing or invalid authentication |
| `402` | Payment required - Insufficient credits |
| `403` | Forbidden - Insufficient permissions |
| `404` | Not found - Resource doesn't exist |
| `429` | Rate limited - Too many requests |
| `500` | Internal server error |

## Rate Limits

The API is rate limited to ensure fair usage:

| Plan | Requests per minute |
|------|---------------------|
| Free | 60 |
| Pro | 300 |
| Enterprise | Custom |

<Warning>
When you exceed the rate limit, you'll receive a `429 Too Many Requests` response. Implement exponential backoff in your client to handle this gracefully.
</Warning>
