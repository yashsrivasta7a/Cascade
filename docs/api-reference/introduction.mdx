## Base URL

```
https://flowsmiths.vercel.app/api/v1
```

## OpenAPI Specification

The full OpenAPI 3.0 specification is available at:

```
https://flowsmiths.vercel.app/api/openapi
```

You can import this into tools like Postman, Insomnia, or any OpenAPI-compatible client.

## Available Endpoints

### Workflows

Manage your AI workflows - create, update, execute, and delete.

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/workflows` | [List all workflows](/api-reference/workflows/list) |
| `GET` | `/workflows/{id}` | [Get a specific workflow](/api-reference/workflows/get) |
| `POST` | `/workflows` | [Create a new workflow](/api-reference/workflows/create) |
| `PATCH` | `/workflows/{id}` | [Update a workflow](/api-reference/workflows/update) |
| `DELETE` | `/workflows/{id}` | [Delete a workflow](/api-reference/workflows/delete) |
| `POST` | `/workflows/{id}/duplicate` | [Duplicate a workflow](/api-reference/workflows/duplicate) |
| `POST` | `/workflows/{id}/execute` | [Execute a workflow](/api-reference/workflows/execute) |

### Executions

Track and manage workflow executions.

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/executions` | [List all executions](/api-reference/executions/list) |
| `GET` | `/executions/{id}` | [Get execution details](/api-reference/executions/get) |
| `POST` | `/executions/{id}/cancel` | [Cancel an execution](/api-reference/executions/cancel) |
| `GET` | `/executions/{id}/stream` | [Stream execution updates](/api-reference/executions/stream) |

### Credits

Monitor and manage your credit balance.

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/credits/balance` | [Get current credit balance](/api-reference/credits/balance) |
| `GET` | `/credits/stats` | [Get credit usage statistics](/api-reference/credits/stats) |

### Dashboard

Get aggregate statistics and overview data.

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/dashboard/stats` | [Get dashboard statistics](/api-reference/dashboard/stats) |

## Response Format

All responses are returned as JSON with the following structure:

### Success Response

```json
{
  "data": { ... },
  "meta": {
    "requestId": "req_abc123"
  }
}
```

### Error Response

```json
{
  "error": {
    "code": "NOT_FOUND",
    "message": "Workflow not found"
  }
}
```

## HTTP Status Codes

| Status | Description |
|--------|-------------|
| `200` | Success |
| `201` | Created successfully |
| `400` | Bad request - Invalid parameters |
| `401` | Unauthorized - Missing or invalid authentication |
| `402` | Payment required - Insufficient credits |
| `403` | Forbidden - Insufficient permissions |
| `404` | Not found - Resource doesn't exist |
| `429` | Rate limited - Too many requests |
| `500` | Internal server error |

## Rate Limits

The API is rate limited to ensure fair usage:

| Plan | Requests per minute |
|------|---------------------|
| Free | 60 |
| Pro | 300 |
| Enterprise | Custom |

<Warning>
When you exceed the rate limit, you'll receive a `429 Too Many Requests` response. Implement exponential backoff in your client to handle this gracefully.
</Warning>
