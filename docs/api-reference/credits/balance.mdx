---
title: 'Get Credit Balance'
api: 'GET /api/v1/credits/balance'
description: 'Returns the current credit balance for the authenticated user'
---

<RequestExample>
```bash cURL
curl -X GET "https://cascade.vercel.app/api/v1/credits/balance" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

```javascript JavaScript
const response = await fetch('https://cascade.vercel.app/api/v1/credits/balance', {
  headers: {
    'Authorization': 'Bearer YOUR_API_KEY'
  }
});
const data = await response.json();
console.log(`Balance: ${data.formatted}`);
```
</RequestExample>

<ResponseExample>
```json 200
{
  "credits": 150000,
  "formatted": "150K",
  "dollarValue": "$15.00"
}
```
</ResponseExample>

## Credit Values

| Credits | Dollar Value |
|---------|--------------|
| 1,000 | $0.10 |
| 10,000 | $1.00 |
| 100,000 | $10.00 |

## Node Costs

Different node types have different credit costs:

| Node Type | Credits |
|-----------|---------|
| Text Generation | ~1,000 |
| Image Generation | ~5,000 |
| Video Generation | ~20,000 |
| Audio Generation | ~3,000 |
