---
title: 'Get Credit Statistics'
api: 'GET /credits/stats'
description: 'Returns detailed credit statistics including spending history and totals'
---

<RequestExample>
```bash cURL
curl -X GET "https://flowsmith-ys7.vercel.app/api/v1/credits/stats" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</RequestExample>

## Transaction Types

| Type | Description |
|------|-------------|
| `EXECUTION` | Credits spent on workflow/node execution |
| `PURCHASE` | Credits purchased |
| `BONUS` | Promotional or referral credits |
| `REFUND` | Refunded credits |
| `ADJUSTMENT` | Manual balance adjustment |
