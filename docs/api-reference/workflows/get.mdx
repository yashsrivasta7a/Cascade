---
title: 'Get Workflow'
api: 'GET /api/v1/workflows/{id}'
description: 'Returns a single workflow by ID with recent executions'
---

<ParamField path="id" type="string" required>
  The unique identifier of the workflow
</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://flowsmiths.vercel.app/api/v1/workflows/clm123abc" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</RequestExample>
