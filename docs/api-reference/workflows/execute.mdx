## Overview

This endpoint triggers the execution of a workflow. It validates the workflow, checks available credits, and returns an execution ID that can be used to track progress. The workflow ID is passed in the request body.

## Request Body

<ParamField body="workflowId" type="string" required>
  The unique identifier of the workflow to execute
</ParamField>

<ParamField body="inputs" type="object">
  Optional input values for the workflow's input nodes. Keys are node IDs, values are the input data.
</ParamField>

## Request

<CodeGroup>
```bash cURL
curl -X POST https://cascade.vercel.app/api/workflow/trigger \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"workflowId": "your-workflow-id"}'
```

```javascript JavaScript
const response = await fetch(
  'https://cascade.vercel.app/api/workflow/trigger',
  {
    method: 'POST',
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      workflowId: 'your-workflow-id',
      inputs: {
        'input-1': 'Your input value'
      }
    })
  }
);
const data = await response.json();
```

```python Python
import requests

response = requests.post(
    'https://cascade.vercel.app/api/workflow/trigger',
    headers={
        'Authorization': 'Bearer YOUR_API_KEY',
        'Content-Type': 'application/json'
    },
    json={
        'workflowId': 'your-workflow-id',
        'inputs': {
            'input-1': 'Your input value'
        }
    }

data = response.json()
```
</CodeGroup>

## Response

<ResponseField name="executionId" type="string">
  Unique identifier for the execution. Use this to track progress.
</ResponseField>

<ResponseField name="triggerRunId" type="string">
  Internal run ID for the background execution task
</ResponseField>

<ResponseField name="status" type="string">
  Initial status of the execution. Always `PENDING` on successful creation.
</ResponseField>

<ResponseField name="estimatedCost" type="number">
  Estimated credit cost for running this workflow
</ResponseField>

### Success Response (200)

```json
{
  "executionId": "exec_abc123def456",
  "triggerRunId": "run_xyz789",
  "status": "PENDING",
  "estimatedCost": 15
}
```

## Execution Flow

1. **Validation** - The workflow is validated to ensure it has nodes
2. **Credit Check** - User's available credits are verified against the estimated cost
3. **Execution Created** - A new execution record is created with `PENDING` status
4. **Background Task** - The workflow is queued for background execution
5. **Tracking** - Use the returned `executionId` to track progress via the [Get Execution](/api-reference/executions/get) or [Stream Execution](/api-reference/executions/stream) endpoints

<Note>
Workflow execution happens asynchronously. The API returns immediately with an execution ID. Use the streaming endpoint for real-time progress updates.
</Note>
