---
title: 'Duplicate Workflow'
api: 'POST /workflows/{id}/duplicate'
description: 'Creates a copy of an existing workflow'
---

<ParamField path="id" type="string" required>
  The unique identifier of the workflow to duplicate
</ParamField>

<Info>
  The duplicated workflow will have "(Copy)" appended to its name and will be unpublished by default.
</Info>

<RequestExample>
```bash cURL
curl -X POST "https://flowsmiths.vercel.app/api/v1/workflows/clm123abc/duplicate" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</RequestExample>

<ResponseExample>
```json 200
{
  "id": "clm789ghi",
  "name": "My Workflow (Copy)",
  "description": "Original description",
  "version": 1,
  "isPublished": false,
  "createdAt": "2024-01-17T12:00:00.000Z",
  "updatedAt": "2024-01-17T12:00:00.000Z"
}
```
</ResponseExample>
