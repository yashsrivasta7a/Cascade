## Bearer Token Authentication

All API requests require authentication using a Bearer token in the `Authorization` header.

```bash
Authorization: Bearer YOUR_API_KEY
```

## Getting Your API Key

1. Log into your [Flowsmith Dashboard](https://flowsmith-ys7.vercel.app)
2. Navigate to **Settings → API Keys**
3. Click **Generate New Key**
4. Copy and securely store your API key

<Warning>
  API keys provide full access to your account. Keep them secure and never expose them in:
  - Client-side JavaScript
  - Public repositories
  - Mobile apps
</Warning>

## Example Request

<CodeGroup>

```bash cURL
curl -X GET "https://flowsmith-ys7.vercel.app/api/v1/workflows" \
  -H "Authorization: Bearer sk_live_abc123..."
```

```javascript JavaScript
const response = await fetch('https://flowsmith-ys7.vercel.app/api/v1/workflows', {
  headers: {
    'Authorization': 'Bearer sk_live_abc123...',
    'Content-Type': 'application/json'
  }
});
```

```python Python
import requests

headers = {
    'Authorization': 'Bearer sk_live_abc123...',
    'Content-Type': 'application/json'
}

response = requests.get(
    'https://flowsmith-ys7.vercel.app/api/v1/workflows',
    headers=headers
)
```

</CodeGroup>

## Error Responses

| Status Code | Description |
|-------------|-------------|
| `401` | Missing or invalid API key |
| `403` | API key doesn't have permission for this action |
| `429` | Rate limit exceeded |

## Rate Limits

| Limit Type | Value |
|------------|-------|
| Requests per minute | 100 |
| Requests per hour | 1,000 |

When you exceed rate limits, you'll receive a `429 Too Many Requests` response with a `Retry-After` header indicating when you can retry.
