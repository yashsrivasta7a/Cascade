# Welcome to Flowsmith

**Flowsmith** is a visual AI workflow builder that lets you create, connect, and execute AI-powered pipelines with an intuitive node-based interface. Build complex AI automations without writing code.

<Note>
  Generate images, create videos, synthesize speech, process text with LLMs – all connected visually.
</Note>

---

## What Can You Build?

<CardGroup cols={2}>
  <Card title="AI Image Pipelines" icon="image">
    Generate images with Seedream, apply transformations, crop, resize, and chain multiple AI models together.
  </Card>
  <Card title="Video Generation" icon="video">
    Create AI videos with Seedance, merge clips with transitions, extract audio, and build end-to-end video workflows.
  </Card>
  <Card title="Audio & Speech" icon="microphone">
    Text-to-speech with ElevenLabs, audio extraction from videos, and audio processing pipelines.
  </Card>
  <Card title="LLM Automations" icon="brain">
    Connect OpenRouter LLMs to analyze content, generate prompts, make decisions, and orchestrate complex logic.
  </Card>
</CardGroup>

## Key Features

<AccordionGroup>
  <Accordion title="Visual Drag-and-Drop Editor" icon="diagram-project">
    Build workflows by dragging nodes onto a canvas and connecting them. No code required.
  </Accordion>
  
  <Accordion title="Real-time Execution" icon="bolt">
    Watch your workflows execute in real-time. See each node's status and output as it happens.
  </Accordion>
  
  <Accordion title="Parallel Processing" icon="layer-group">
    Independent nodes execute simultaneously for maximum speed.
  </Accordion>
  
  <Accordion title="Cloud Processing" icon="cloud">
    Heavy media processing in the cloud. No timeouts, no file size limits.
  </Accordion>
</AccordionGroup>
